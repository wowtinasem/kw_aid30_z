# 전시관 템플릿 (히어로 섹션 + 갤러리)

부여교육지원청 "바이브코딩 교원연수 작품 전시관"에서 완성한 형식을
어느 프로젝트에나 재사용할 수 있게 정리한 단일 HTML 템플릿입니다.

- 파일: `exhibition-template.html` — 외부 라이브러리 없음, 이 파일 하나로 동작
- 브라우저로 바로 열거나, GitHub Pages·Vercel 등 아무 정적 호스팅에 올리면 됩니다

## 포함된 기능

| 영역 | 기능 |
| ------ | ------ |
| 기관 표시줄 | 로고 이미지 또는 기관명 텍스트 + 프로그램명 |
| 히어로 | 점 격자·빔 스윕 무대, 키네틱 타이포(단어별 등장 + 시머), 타이핑 프롬프트 카드, 글래스 연꽃(5초 개화 루프) + 디지털 닷 글로브 |
| 갤러리 | 4열 그리드(태블릿 2열·모바일 1열), 부문 필터, 작품 번호 배지(우상단), OG 이미지 썸네일 |
| 도록형 모달 | 작품 주제·사용 방법·바로가기 버튼, Esc 닫기·포커스 트랩·포커스 복원 |
| 자동 전시 모드 | 무조작 40초 → 작품 카드 자동 순환(주소 연결된 작품만), 조작 시 즉시 해제 |
| 기타 | 모든 연출은 OS "동작 줄이기" 설정과 무관하게 항상 재생(행사장 PC 대응) |

## 사용 방법 — 수정은 3곳만

파일을 열면 `<script>` 상단에 수정 구역이 표시되어 있습니다.
**HTML·CSS는 건드릴 필요 없습니다.**

### ① `SITE` — 사이트 기본 정보

기관명(또는 로고 경로), 프로그램명, 히어로 문구(작은 제목·큰 제목 단어들·강조 제목·소개문),
타이핑 프롬프트 목록, 섹션 제목, 배지 형식, 푸터 문구, 자동 전시 타이밍.

```js
const SITE = {
  orgName: "충청남도부여교육지원청",
  orgLogo: "logo.png",          // "" 이면 텍스트로 표시
  titleWords: ["바이브코딩", "교원연수"],
  titleGlow: "작품 전시",
  ...
};
```

### ② `CATEGORIES` — 부문(필터)

필요한 만큼 추가·삭제합니다. 필터 버튼과 카드 칩 색이 자동 생성됩니다.

```js
const CATEGORIES = [
  { key:"초등", label:"초등부", color:"#2E75B6", tint:"#E8F1F9" },
  { key:"중등", label:"중등부", color:"#2F7D5B", tint:"#E9F4EE" },
];
```

### ③ `ITEMS` — 작품 목록

작품 하나당 객체 하나. 필드 설명은 파일 안 주석에 있습니다.

```js
{ group:"규암초등학교", author:"김경미", category:"초등",
  title:"도자기 타임머신", topic:"...", usage:"① ...\n② ...",
  url:"https://...", emoji:"🏺", image:"https://.../og.png" },
```

- `url`이 비면("") 버튼이 "준비 중"으로 표시되고 자동 순환에서 제외됩니다
- `image`는 해당 앱의 오픈그래프 이미지 주소를 넣는 것을 권장 (없으면 이모지+자동 색상 카드)
- 총 개수를 **4의 배수**로 맞추면 그리드 줄이 딱 떨어집니다 — 빈 자리는 대기 카드 형식으로

## 색상 테마 바꾸기

`<style>` 맨 위 `:root` 변수만 수정하면 전체 톤이 바뀝니다
(`--navy` 주조색, `--navy-deep` 상단바·푸터, `--blue` 포인트, `--hero-bg` 히어로 배경).

## 오픈그래프(링크 미리보기) 넣기

`<head>`에 주석 처리된 OG 메타태그 6줄이 있습니다.
배포 주소가 정해지면 주석을 풀고 주소·문구를 채우세요.
미리보기 이미지는 히어로를 1200×630으로 캡처해 `og.png`로 두면 됩니다.
