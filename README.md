# AID+30 작품 전시관 — 운영 가이드

계원예술대학교 AID+30 수강생의 수업 결과물을 전시하는 정적 웹사이트입니다.
이 문서는 **작품을 추가·수정하는 분**을 위한 안내입니다. 코드를 몰라도 됩니다.

```text
index.html        화면·동작 (건드리지 않습니다)
data/items.js     작품 데이터 — 수정은 이 파일에서만 합니다
img/              썸네일 캡처, 로고, og.png
```

## 미리 보기

파일을 더블클릭으로 열면 `data/items.js` 로드가 막힙니다. 간단한 서버로 여세요.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000> 접속.

## 작품 하나 추가하기

`data/items.js`를 열어 `ITEMS` 배열에 아래 형태의 객체를 붙여 넣고 저장하면 끝입니다.

```js
{
  no: 4, cohort: "2",                  // 기수 안에서의 번호 — (기수, 번호) 조합이 겹치면 안 됩니다
  group: "○○과", author: "김○○",       // 실명은 공개 동의를 받은 경우에만
  title: "작품 이름",
  topic: "무엇을 하는 도구인지 2문장 이내.",
  usage: "① 첫 단계\n② 둘째 단계",
  prompt: "AI에게 실제로 시킨 말.",      // ★ 이 전시관의 핵심 — 가능한 한 채우세요
  links: {
    app:   "https://...",              // 없으면 "" — 버튼이 '준비 중'으로 표시됩니다
    video: "https://youtu.be/...",     // 유튜브 주소 — 썸네일이 자동으로 걸립니다
    extra: ""
  },
  image: "img/2-04-name.png",          // 대표 화면 캡처. "" 이면 유튜브 썸네일 → 이모지 순 자동 대체
  emoji: "🎨"
},
```

- 구글폼으로 제출을 받는 경우, 폼 항목과 필드의 1:1 대응은
  `AID30-exhibition-spec.md` **부록 A**에 있습니다. 응답 시트를 그대로 옮기면 됩니다.
- 이미지는 **16:9 비율, 장당 300KB 이하** 권장. 파일명은 영문·숫자만 (`img/2-04-name.png`).
- 새 기수를 시작하면 `COHORTS` 배열 **맨 앞**에 추가하세요. 첫 화면 기본 선택이 됩니다.

```js
const COHORTS = [
  { key: "3", label: "3기", period: "2027 상반기" },   // ← 새 기수를 맨 앞에
  ...
];
```

## 올리기 전에 확인 — 개인정보·저작권

공개 웹입니다. 작품을 추가할 때마다 확인하세요 (상세: 명세 13절).

- [ ] 실명·소속 공개 동의를 받았는가 (미동의자는 `김○○` 형태)
- [ ] 캡처 이미지에 계정 이메일·프로필 사진이 찍혀 있지 않은가
- [ ] 유튜브 영상이 일부공개 이상인가, 자료 링크가 "뷰어" 권한인가
- [ ] 이메일·전화번호·API 키가 데이터에 섞이지 않았는가

하나라도 미확인이면 해당 작품의 `links`를 비워 "준비 중"으로 두고 올리세요.
